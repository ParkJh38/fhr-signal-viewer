# FHR Signal Viewer

브라우저에서 바로 실행하는 읽기 전용 FHR(Fetal Heart Rate)·UC(Uterine Contraction/TOCO) 시계열 및 패턴 Label 열람 도구입니다. 서버 설치, 계정 로그인, 파일 업로드 없이 압축을 푼 데이터 폴더를 선택해 로컬에서만 확인할 수 있습니다.

> 이 도구는 데이터 검토와 시각화를 돕기 위한 뷰어입니다. 임상적 진단, 치료 결정 또는 의료기기 대체 용도로 사용하지 않습니다.

## 주요 기능

- FHR와 UC/TOCO 파형을 같은 시간 구간에서 함께 열람
- Label 구간을 차트에 겹쳐 표시하고, Label 유형별 표시/숨김 및 목록 이동
- IHU/NIA, KMU, SNU의 병원·Raw/Processed 분류로 케이스를 나누어 조회
- 레코드 ID 검색, 병원/버전 필터, Label JSON 보유 여부 필터, 길이 범위 필터
- 많은 케이스에서도 좌측 목록을 스크롤해 계속 탐색하고, 선택 위치를 유지한 채 이전/다음 케이스 검토
- 흰색 차트 배경과 높은 대비로 화면 캡처 후 PPT에 바로 활용

Raw와 Processed 데이터는 의도적으로 분리해 표시합니다. 서로 다른 버전의 신호나 Label을 한 레코드에 섞지 않습니다.

## 빠른 시작

1. Chrome 또는 Edge에서 `FHR_Signal_Viewer.html`을 엽니다.
2. 첫 화면에서 **데이터 폴더 선택**을 눌러 압축을 푼 데이터의 최상위 폴더를 선택합니다.
3. 목록 생성이 끝나면 좌측의 검색·병원·버전 필터로 검토할 케이스를 좁힙니다.
4. 케이스를 선택해 FHR/UC 차트와 Label을 확인합니다.
5. 상단의 표시 구간과 이동 시점으로 시간 창을 옮기거나, **이전 케이스 / 다음 케이스**로 필터 결과를 순차 검토합니다.

ZIP 파일을 직접 여는 방식이 아닙니다. 반드시 먼저 압축을 풀고, 그 상위 폴더를 선택해야 합니다.

## 입력 폴더와 파일 인식

선택한 폴더 및 하위 폴더에서 파일명 접미사를 기준으로 레코드를 묶습니다. 하나의 레코드는 같은 접두사(예: `KMU0003`)를 공유하는 파일들로 인식됩니다.

```text
selected-folder/
└── KMU/
    ├── KMU0003_origin.csv
    ├── KMU0003_summary.csv
    ├── KMU0003.json
    └── KMU0003.cts
```

| 파일 | 용도 | 필수 여부 |
| --- | --- | --- |
| `<record>_origin.csv` | 원본 신호 | 둘 중 하나 필요 |
| `<record>_summary.csv` | 요약/처리 신호 | 둘 중 하나 필요 |
| `<record>.json` | 선택적 Label 정보 | 선택 |
| `<record>.cts` | 연관 파일 식별 | 선택 |
| `_summary.csv` | 처리 결과 요약 정보 | 선택 |

`_origin.csv`와 `_summary.csv`가 모두 있으면 뷰어는 `_summary.csv`를 우선 사용합니다. 이름이나 폴더 구조가 일반적인 규칙과 다르면 병원/버전 분류를 확인해 주세요.

### 신호 CSV 열

신호 CSV는 다음 열을 기준으로 읽습니다.

| 열 | 역할 | 필요 여부 |
| --- | --- | --- |
| `TM` | 인접 샘플 간 시간 간격 | 필수 |
| `FHR1` 또는 `FHR` | 태아 심박 신호 | 필수 |
| `UC` 또는 `TOCO` | 자궁수축 신호 | 선택 |
| `CUM_TM` | 누적 시간 | 선택 — 길이 인덱싱에 사용 |

`TM`과 `FHR1`(또는 `FHR`)이 없으면 해당 신호 CSV를 열 수 없습니다. `UC`/`TOCO`가 없는 경우에는 UC 차트에 결측으로 표시될 수 있습니다.

### Label JSON 형식

Label JSON은 `labeling-data` 배열을 읽습니다. 각 항목의 최소 정보는 `type`, `start_ms`, `end_ms`입니다.

```json
{
  "labeling-data": [
    {
      "type": "1",
      "start_ms": 60000,
      "end_ms": 90000,
      "recheck_yn": false,
      "review_green_yn": true,
      "review_red_yn": false
    }
  ]
}
```

| 코드 | 표시 이름 |
| --- | --- |
| `1` | Acceleration |
| `2` | Variable deceleration |
| `3` | Early deceleration |
| `4` | Late deceleration |
| `5` | Prolonged deceleration |
| `6` | Uterine contraction |
| `7` | Spontaneous deceleration |
| `8` | Prolonged acceleration |
| `9` | Sinusoidal pattern |
| `10` 또는 그 외 | Other / excluded |

JSON이 없거나 비어 있어도 신호는 열람할 수 있습니다. 읽을 수 없는 JSON은 Label 없음과 구분해 상태로 표시됩니다.

## 탐색과 필터 사용법

### 케이스 목록

- **레코드 ID 검색**: 입력한 문자열이 포함된 케이스만 표시합니다.
- **병원 / 버전**: 병원별로 펼쳐 Raw와 Processed를 독립적으로 선택합니다.
- **Label JSON이 있는 레코드만**: Label 파일이 확인된 케이스만 남깁니다.
- **목록 스크롤**: 초기 목록 일부를 표시한 뒤 아래로 스크롤하면 다음 케이스가 이어서 나타납니다.
- **순차 검토**: 상세 화면의 이전/다음 버튼은 현재 필터 결과 안에서 이동합니다.

병원과 버전은 파일 경로 및 레코드 ID 관례를 이용해 자동 분류합니다. 현재 IHU/NIA, KMU, SNU 구조를 지원하며, 경로에 `processed`가 포함된 SNU 자료는 Processed로 표시합니다.

### 길이 필터

길이 필터는 대용량 폴더를 처음 열 때 불필요한 전체 읽기를 피하기 위해 별도로 준비합니다.

1. 좌측 **길이 정보 준비**를 누릅니다.
2. 뷰어가 각 신호 파일의 `CUM_TM` 열과 마지막 시간 정보를 브라우저 안에서 읽어 길이를 계산합니다.
3. 준비가 끝나면 최소/최대 분 단위 값을 입력해 케이스를 좁힙니다.

`CUM_TM`이 없는 파일은 길이 인덱싱에서 제외될 수 있습니다. 선택한 케이스를 실제로 열면 전체 신호를 읽어 상세 길이를 표시합니다.

### 차트와 Label

- 마우스를 파형 위에 올리면 해당 시점의 FHR·UC 값을 확인할 수 있습니다.
- **Label 표시**에서 유형별 표시/숨김을 바꿀 수 있습니다.
- 현재 시간 창 안의 Label은 하단 목록에 나타납니다.
- Label 목록을 누르면 해당 Label 구간으로 차트가 이동합니다.
- FHR에는 FHR 관련 Label을, UC 차트에는 Uterine contraction Label을 표시합니다.

## 개인정보와 데이터 보호

- 선택한 폴더의 데이터는 브라우저의 파일 선택 기능으로만 읽습니다.
- 서버 통신, 파일 업로드, 데이터 수정, 자동 저장은 수행하지 않습니다.
- 이 공개 저장소에는 HTML 소스와 문서만 포함합니다.
- 환자 데이터, Label JSON, CSV/CTS, 압축파일, 로컬 테스트 데이터, 검사 로그, 화면 캡처는 커밋하지 않습니다.

실제 데이터를 담은 화면을 공유하거나 PPT에 삽입할 때에는 환자 식별 가능 정보와 메타데이터가 노출되지 않도록 별도로 확인해 주세요.

## 브라우저와 성능 참고

- 폴더 선택 기능 때문에 Chrome 또는 Edge 사용을 권장합니다.
- 별도 서버, 빌드 도구, 외부 라이브러리가 필요 없는 단일 HTML 도구입니다.
- 첫 폴더 선택 시에는 파일 구조를 읽어 목록을 만들고, 상세 신호는 해당 케이스를 선택할 때 읽습니다.
- 레코드 수가 매우 많은 경우 길이 정보 준비에 시간이 걸릴 수 있으며, 이 작업도 모두 로컬 브라우저에서 진행됩니다.
